# 📝 Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-04

### Added

- Script discovery by `.sh` extension or shell shebang, optionally recursive
- Exact matching of scripts to `<name>.timer` and `<name>.service` in user and system scope
- Interactive menu, `list` with JSON and verbose output
- Install wizard and `install` command rendering units from templates
- `edit-timer`, `edit-service`, and `uninstall` commands
- Dry runs for every changing action
